# 独立版：外部 AI 与语音服务方案

日期：2026-09-19。状态：已实施，待真实服务 Key 与真机联调。

## 目标和现状

个人构建完全脱离 Echo Loop 账号、会员、配额和官方运行服务。所有 AI 学习能力使用用户配置的第三方服务；本地媒体、学习进度、收藏、备份继续保留。个人包沿用现有包名和签名覆盖升级。

依赖盘点已确认：
- 外部文本 AI 已支持翻译、解析、意群、词典和聊天。
- 云端转录依赖官方上传、任务轮询和字幕接口；复述评估同时受登录与会员门控，外部客户端明确拒绝此能力。
- 启动和前台恢复会涉及官方合集、远程配置、权益及更新请求；百度网盘授权也依赖官方 OAuth 桥接。
- ASR/TTS 模型、离线词典和发音包下载使用官方 CDN。只取消登录弹窗无法实现独立运行。
- 旧版备份恢复失败尚缺实际文件/日志。当前格式未限制来源包名，不应直接归因于两个 App。

## 推荐实现方式

1. **独立构建模式（采用）。** 个人构建默认启用，集中控制启动依赖、路由与服务选择；独立包只提供外部 AI，未配置时明确引导配置。保留上游实现便于维护，但不能进入官方网络路径。
2. 全面删除账户、订阅和官方服务实现：涉及大范围重构、路由和测试调整，不适合作为本次接入前提。
3. 自建中转后端：可以统一厂商协议，但引入部署维护要求。当前采用设备直连服务商/用户自部署服务。

“独立模式”不是允许用户切回官方的 UI 开关；个人包始终使用独立路径，也不把恢复备份中的旧配置当作官方服务授权。

## 首批语音服务

根据用户“常见、国产”的偏好，本次只接入阿里云百炼 Paraformer 和豆包录音文件极速版。

- 阿里云通过 Paraformer WebSocket 接口，按官方协议发送音频并解析时间戳。
- 豆包通过录音文件极速版 HTTP 接口，支持本地文件 base64，响应提供 utterances 句级和 words 词级时间戳。
- 两者均由用户填写自己的 API Key；豆包兼容新控制台单 API Key 和旧控制台 App ID + Access Token。
- FunASR、Whisper/LocalAI、硅基流动等暂不接入。

## 功能行为

| 原能力 | 独立版 |
| --- | --- |
| 登录、账户、会员、试用额度 | 移除独立包的入口和前置条件，不初始化对应服务 |
| 文本 AI | 复用现有外部客户端，配置缺失时进入设置 |
| 音频/视频转录字幕 | 直接连接所选语音服务，结果转为现有字幕模型 |
| 复述 AI 评估 | 先外部语音识别，再由外部文本模型评价内容和表达 |
| 跟读、离线识别、本地播放、学习与复习 | 保留本地逻辑，无登录要求 |
| 官方合集在线发现/更新 | 保留现有官方服务，不在本次独立 AI 改造中替换 |
| 百度内嵌授权导入 | 保留现有官方 OAuth 桥接，不在本次改造中替换 |
| 官方版本检查 | 停止官方检查，提供个人仓库 Actions 下载入口，沿用固定签名升级 |
| 备份恢复 | 保留本地备份迁移；获得实际备份后单独修复“无效备份”问题 |

官方合集、百度网盘内嵌授权和官方词典资源按用户确认继续使用现有官方服务。它们不属于本次外部语音改造范围。

## 设置与凭据

- 文本 AI 和语音识别分别配置服务、地址、模型和 Key，允许不同服务商。
- 托管服务预填端点/模型；自部署允许填写地址，密钥是否必需按协议认证方式确定。
- 复用现有系统安全存储，语音与文本凭据独立；Key 不进入日志、普通设置或备份。
- 既有外部文本配置保留；旧 Echo Loop 选项在独立包中转为待配置，失败绝不回退官方。
- 未配置、配置加载失败、服务余额不足、鉴权失败、限流、超时均有可执行提示；不弹官方登录/付费。
- 云服务费用由用户的服务商账户承担。

## 转录与评估职责

语音服务接口负责协议、上传/流式发送、响应校验与取消；纯 Dart 编排器负责处理步骤，provider/controller 负责状态和 UI 连接。复用已有抽音轨、压缩、SRT 生成、数据库保存能力，避免另建媒体或学习数据源。

转录顺序：验证配置与文件 → 抽取音轨/按服务要求转码 → 上传或流式发送 → 解析时间戳 → 本地分句/合并 → 保存字幕。
- 限制按服务实际能力处理，移除官方会员时长门控。HTTP 路径保留压缩，仍超过服务限制则明确报错；流式接口按协议发送，不能把整段大文件装入内存。
- 句级时间戳必须真实存在，检查非负、有限、顺序与起止关系；无时间戳时明确不支持生成字幕，不能平均分配时间伪造对齐。
- 单词时间戳可选；只有句级结果也能学习。静音/空结果单独处理。
- 保留已有短句合并开关，在本地使用真实时间边界；复用已有分句能力，不通过文本模型猜时间。
- 每次任务持有唯一标识与配置快照；取消、切换配置、删除材料和销毁 owner 时失效，提交前再次校验。
- 失败保留原媒体和原字幕；数据库写入失败不得标记完成。创建临时文件的一方负责清理。
- 不自动重试可能重复计费的请求。

复述评价：语音转录 → 文本模型对照原文输出结构化评价 → 复用已有报告。
- 评价内容要点、语法和表达，不把文本识别结果当作专业发音评分。
- 空转录或识别失败不请求文本模型；无效 JSON 不记为成功。
- 缓存绑定录音 attempt 和文本/语音配置；切换录音或服务立即取消旧流程。
- 评价器通过接口注入语音与文本客户端，便于独立测试失败路径和状态转换。

## 其余官方依赖

- 启动、回前台不执行官方认证、订阅、权益、合集同步和远程配置请求；独立模式使用本地配置。
- 停止上游 Firebase/PostHog 使用数据上报，保留本地诊断日志。
- 已安装 ASR/TTS/词典/发音资源继续使用。新的 ASR/TTS 下载优先改为模型项目公开发布源，核对归档结构、模型文件、许可和校验值后接入。
- 官方定制词典和发音包继续使用现有资源服务；本次不替换、不关闭其下载。
- 保留项目开源许可与来源署名，它们不是运行服务依赖。
- 测试包括恢复旧备份后的配置，确保旧设置不会重新开启官方服务。

## 实施顺序与验证

按顺序完成一个子任务后再进入下一个：
1. 独立构建与文本/语音配置：config、model、provider、secure store、settings、个人 workflow。
2. 三类语音适配器与转录接入：协议测试先行，再接 transcription_task_provider 和 manage_subtitles_sheet。
3. 复述编排与报告：复用文本客户端、结果模型和报告组件。
4. 启动/路由/导入/资源/更新/埋点收尾，验证无官方网络依赖。
5. 旧备份迁移：获得文件或日志后复现并增加修复前失败的回归测试。

每步执行相关 analyze/test。重点验证协议地址和认证、时间戳解析、无效/空响应、网络失败、取消及迟到回调、存储失败、临时文件清理；页面验证未登录可用且错误不引导官方。
独立模式边界测试覆盖启动、回前台、AI 操作、缺失离线资源、恢复旧设置时均无官方请求。
跨核心模块收尾按仓库规范尝试 scripts/check.sh；遇平台限制明确报告并运行适用的等价检查。
真机验证个人 APK 覆盖升级保留数据、外部语音生成同步字幕、复述评价、离线核心学习。真实服务需用户填写 Key 后联调，不在自动测试中使用真实付费凭据。

## 需要审阅的产品边界

首批采用阿里云百炼和豆包语音识别；官方合集、百度网盘内嵌授权和官方词典资源继续使用现有官方服务。
